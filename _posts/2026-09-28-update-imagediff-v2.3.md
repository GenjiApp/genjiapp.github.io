macOS用画像比較アプリ「ImageDiff」の ver. 2.3 をリリースしました。

- [アプリ紹介ページ](/mac/imagediff/)
- [Mac App Store](https://apps.apple.com/jp/app/imagediff-2/id1602522152?mt=12)

ver. 2.3 の変更点は、

- システム要件を macOS 27 以上に変更
- macOS 27 における UI の乱れを修正
- 操作 UI の調整

です。どうぞよろしく。
